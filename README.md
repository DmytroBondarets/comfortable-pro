# BYTEEX landing page

This project is a static storefront landing page built to match the provided mockups, including desktop and mobile responsive layouts.

## Run locally

Open the folder in a browser, or serve it with a local web server:

```bash
cd "c:\Users\bond\comfortable pro"
python -m http.server 8000
```

Then visit http://localhost:8000

## Files

- `index.html` — page structure
- `styles.css` — visual styling and responsive layout
- `script.js` — FAQ interaction
